# Bible Reader content — RO-Romanian

This repository contains the Bible Reader SD-card content for **RO-Romanian**.

## Directory layout

- `text/RO-Romanian/` — all Bible translations and their original nested folder structure.
- `audio/RO-Romanian/` — audio Bible book folders and chapter MP3s.
- `gospel/RO-Romanian/` — Gospel files, retaining original names such as `Gospel.txt` and `Gospel.mp3`.

Copy these folders into the root of the Bible Reader `SDCARD` staging directory.
Do not rename files or flatten directories: the firmware expects the original paths.
